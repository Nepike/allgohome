

## Тема

Моделирование системы навигации мобильных роботов с использованием алгоритма A* и фильтров оценки состояния (EKF, UKF, Particle Filter)

---

В данной лабораторной работе была разработана программная система моделирования движения мобильных роботов на плоском полигоне с препятствиями. Основной задачей системы является реализация процедуры «По домам», в рамках которой каждый робот должен построить маршрут от текущего положения до своей домашней клетки с обходом препятствий.

Для построения маршрута используется алгоритм поиска пути A* на дискретной клеточной карте. Движение робота моделируется с использованием кинематической модели мобильного робота с управлением линейной и угловой скоростью.

Дополнительно рассматривается задача оценки состояния робота по шумным данным системы компьютерного зрения (две камеры с ArUco-маркерами). Поскольку измерения содержат шум, используются фильтры:

- EKF (Extended Kalman Filter)
- UKF (Unscented Kalman Filter)
- Particle Filter

---


## Модель пространства

Полигон представлен в виде сетки:

- каждая клетка = размер робота
- препятствия занимают соседние клетки (инфляция)

Инфляция препятствий используется для предотвращения застреваний.

---

## Алгоритм A*

Используется классический A*:

f(n) = g(n) + h(n)

где:

- g(n) — стоимость пути
- h(n) — эвристика (Манхэттенское расстояние)

h(n) = |x_{goal} - x| + |y_{goal} - y|

Результат — последовательность клеток (waypoints).

---

## Модель робота

Состояние:
x = [x, y, θ]

Управление:
u = [v, ω]

---

## Модель измерений

Камеры дают шумные данные:

z = [x_m, y_m, θ_m]

Добавляется гауссов шум:

z = x +N(0, σ^2)

Также возможна потеря измерений.
(вероятность что камера "потеряет" кадры)

---

## Кинематика

* xₖ₊₁ = xₖ + v·cos(θₖ)·Δt
* yₖ₊₁ = yₖ + v·sin(θₖ)·Δt
* θₖ₊₁ = θₖ + ω·Δt

---

## Ошибки

Позиционная ошибка:

e = sqrt[(x - x_est)^2 + (y - y_est)^2]

Угловая ошибка:

e_θ = |θ - θ_est|


---

## Управление

Путь A* — это дискретная ломаная.

Для движения используется waypoint-контроллер:

1. берется следующая клетка пути
2. вычисляется угол:
θ_{target} = atan2(y_t - y, x_t - x)

3. ошибка:
e_θ = θ_{target} - θ

4. управление (П-ргеулятор):
ω = k * e_θ

5. линейная скорость подается только при выравнивании угла
