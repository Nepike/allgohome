# ALLGOHOME — Симулятор навигации мобильных роботов

Интерактивный симулятор процедуры **«По домам»**: каждый робот строит маршрут от текущей позиции до своей домашней клетки, объезжая препятствия. Параллельно сравниваются три фильтра оценки состояния на зашумлённых данных камеры.

---

## Быстрый старт

### Необходимое ПО
* Python 3.11+ (Возможно подойдет 3.10+)

### PowerShell / bash
```bash
# Клонирование репозитория
git clone https://github.com/Nepike/allgohome
# (не нужно, если уже скачан архив)

# Создание и активация виртуального окружения Python
python3 -m venv virtualenv
. virtualenv/bin/activate

# Установка нужных пакетов Python
pip install -r requirements.txt

# Запуск
python main.py
```

> Папка `cursors/` должна лежать рядом с `main.py` — в ней хранятся PNG-иконки для курсоров инструментов.

## Интерфейс

Окно разделено на три панели.

**Левая — инструменты:**
- `Draw Walls` / `Erase Walls` — рисование и стирание препятствий кликами по карте (курсор меняется; повторный клик по той же кнопке снимает режим).
- `Clear Map` — полный сброс карты, роботов и симуляции.
- Форма **New Robot** — добавление робота: задаются стартовая клетка `(X, Y)`, начальный угол `θ` в радианах и домашняя клетка `(Home X, Home Y)`.

**Центральная — карта:**
- Сетка `GRID_W × GRID_H` клеток (`CELL_SIZE px` каждая).
- Тёмные клетки — препятствия; красноватые — зона инфляции (буфер вокруг препятствий).
- Цветные квадраты — домашние клетки роботов; кружки со стрелкой — сами роботы.
- Чёрная линия — реальная пройденная траектория; цветная пунктирная — маршрут A*.
- Лог внизу фиксирует все события (требует доработки).

**Правая — графики и управление симуляцией:**
- `Start Simulation` — запускает симуляцию активного робота (или переходит к следующему, если текущий уже дома).
- `Pause Simulation` — пауза/продолжение.
- `EKF / UKF / PF Filter` — переключение активного фильтра (**влияет на управление роботом** и выделенный график траектории). _Необходимо нажимать после начала симуляции._
- Три графика: траектории, ошибка позиции, ошибка угла — обновляются в реальном времени.

Роботы симулируются **по очереди**: пока один не достиг дома, следующий не стартует.

---

## Как работает симуляция (один шаг)


1. Контроллер читает оценку состояния активного фильтра → вычисляет (v, ω)
2. Истинное состояние робота обновляется по кинематической модели
3. Камера генерирует шумное измерение (или пропускает кадр с вероятностью `MEAS_DROP_PROB`%)
4. EKF, UKF и PF выполняют predict → update
5. Карта и графики перерисовываются

_Шаг повторяется каждые **50 мс** (таймер Qt)._

## Алгоритм A*

Строит путь на дискретной сетке от текущей клетки робота до его домашней клетки.

- **Эвристика:** Манхэттенское расстояние `h = |Δx| + |Δy|`
- **Движения:** 4-связность (вверх, вниз, влево, вправо)
- **Заблокированные клетки:** препятствия + зона инфляции (радиус 1 клетка)

Если путь не найден (цель или старт внутри препятствия) — бросается исключение.

---

## Кинематическая модель робота

Состояние `[x, y, θ]`, управление `[v, ω]`:

```
x_{k+1} = x_k + v · cos(θ_k) · Δt
y_{k+1} = y_k + v · sin(θ_k) · Δt
θ_{k+1} = θ_k + ω · Δt
```

---

## Waypoint-контроллер

Последовательно ведёт робота через клетки маршрута A*.

На каждом шаге:
1. Берётся центр текущей целевой клетки.
2. Вычисляется желаемый угол: `θ_target = atan2(Δy, Δx)`.
3. Угловая скорость: `ω = k · (θ_target − θ)`, ограничена `MAX_ANGULAR_SPEED`.
4. Линейная скорость подаётся полностью при `|Δθ| < ANGLE_THRESHOLD рад`; плавно снижается до нуля при `|Δθ| > 1.0 рад` (сначала повернуть, потом ехать).
5. Клетка считается достигнутой при расстоянии `< WAYPOINT_THRESHOLD`.

---

## Модель камеры

Имитирует две камеры с ArUco-маркерами над полигоном. На каждом шаге:

```
z = [x + N(0, σ_pos²),
     y + N(0, σ_pos²),
     θ + N(0, σ_θ²)]
```

С вероятностью `MEAS_DROP_PROB = 0.04` кадр «теряется» — все три фильтра пропускают шаг update.

---

## Фильтры оценки состояния

Все три фильтра работают параллельно на каждом шаге и записывают свои оценки в историю робота.

### EKF (Extended Kalman Filter)
Линеаризует нелинейную модель движения через матрицу Якоби:
```
F = [[1, 0, -v·sin(θ)·Δt],
     [0, 1,  v·cos(θ)·Δt],
     [0, 0,  1           ]]
```
_Можно преевести в обычный KF заменив матрицу Якоби F на единичную_

### UKF (Unscented Kalman Filter)
Аппроксимирует распределение `2n+1 = 7` сигма-точками, пропускает их через нелинейную модель без вычисления Якоби. При вычислении средних угол усредняется через `atan2(Σsin, Σcos)`.

### Particle Filter
Представляет распределение 100(можно задавать) частицами. Каждый шаг:
1. **Predict** — каждая частица движется по модели + случайный шум процесса.
2. **Update** — вес частицы пересчитывается через правдоподобие измерения (гауссиан по позиции и углу).
3. **Resample** — систематический ресэмплинг при `N_eff < 0.6 · N`.

Оценка состояния — взвешенное среднее частиц (угол через `atan2`).

## Метрики качества фильтрации

```
Ошибка позиции:  e_pos = sqrt((x_true − x_est)² + (y_true − y_est)²)
Ошибка угла:     e_θ   = |normalize(θ_true − θ_est)|
```

Все три фильтра отображаются на одном графике для прямого сравнения.

## Параметры (`config.py`)

| Параметр             | Описание                            |
|----------------------|-------------------------------------|
| `GRID_W / GRID_H`    | Размер сетки (клетки)               |
| `CELL_SIZE`          | Размер клетки                       |
| `DT`                 | Шаг симуляции                       |
| `MAX_LINEAR_SPEED`   | Макс. линейная скорость             |
| `MAX_ANGULAR_SPEED`  | Макс. угловая скорость              |
| `ANGULAR_SPEED_K`    | Коэффициент П-регулятора угла       |
| `WAYPOINT_THRESHOLD` | Радиус захвата waypoint             |
| `ANGLE_THRESHOLD`    | Порог «робот смотрит на цель»       |
| `MEAS_POS_STD`       | СКО шума позиции камеры             |
| `MEAS_THETA_STD`     | СКО шума угла камеры                |
| `MEAS_DROP_PROB`     | Вероятность потери кадра            |
| `KALMAN_Q`           | Ковариация шума процесса (EKF/UKF)  |
| `KALMAN_R`           | Ковариация шума измерения (EKF/UKF) |
| `PF_POS_STD`         | СКО шума процесса PF (позиция)      |
| `PF_THETA_STD`       | СКО шума процесса PF (угол)         |
